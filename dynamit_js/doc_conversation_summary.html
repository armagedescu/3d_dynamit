DynamiT — Project Overview

Philosophy

"A lot is going on, I know, but I don't want to care. I want to care only about my stuff. Everything else, just do your job."

DynamiT follows a declarative intent, hidden machinery approach. The developer declares what they have and what they want. Everything in between — shader composition, buffer management, attribute layout, uniform binding — is DynamiT's job, not theirs.

What Is DynamiT

DynamiT is a WebGL2 3D graphics library (with a parallel C++ desktop OpenGL implementation) whose key innovation is automatic runtime GLSL shader generation. Instead of writing shaders by hand, the library composes them based on the data you provide.

Core API

The fluent builder pattern is the vehicle for the philosophy:

// "I have vertices, normals, and a color. Draw triangles. That's all I care about."
new Dynamit(canvas)
    .withVertices3d(verts)
    .withNormals3d(norms)
    .withConstColor([1, 0, 0, 1])
    .drawTriangles();

Features

  • Auto shader generation from high-level descriptions (vertices, normals, colors, textures, transforms)
  • Geometry builders — polar curves (e.g. "1 + 0.5*cos(5*theta)") and Cartesian surfaces
  • Transform matrices — move, scale, rotate
  • Object chaining — multiple Dynamit objects sharing a single program
  • Indexed & strided drawing, triangle fans, texture mapping
  • Symbolic differentiation for computing surface normals from formulas

Architecture

The C++ implementation in dynamit_gl/ serves as the desktop counterpart with the same class structure (Dynamit, GlArrayBuffer, ShaderStrategy). The JavaScript version targets the web via WebGL2 (GLSL 300 ES), maintaining a consistent API across both platforms.
