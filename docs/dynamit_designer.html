Dynamit Designer

Interactive 3D shape builder for designing composite objects from mathematical primitives

What It Is

Dynamit Designer is a Windows desktop application for building 3D shapes visually. You create parts (cones and cylinders) defined by polar formulas, transform each part (move, rotate, scale), and combine them into a single unified mesh.

The result can be exported as C++ source code that uses the Dynamit library, saved as a project file (.dproj), or welded into a single shape for further use.

Workflow

Create parts → Edit formulas → Transform → Weld → Export

1. Create Parts

Each part is a cone or cylinder generated by the PolarBuilder. The geometry lives in the [-1, 1] local coordinate space. You add parts from the Properties Panel.

2. Edit Formulas

Each part's shape is controlled by a polar formula r = f(θ). For example, sin(theta) creates a sphere-like surface, while 1 creates a straight cone or cylinder. You can set the domain (start/end angle), number of sectors and slices, smoothing, and colors.

3. Transform

Each part can be moved, rotated, and scaled independently. Use the visual gizmo handles in the 3D viewport or type exact values in the Properties Panel.

KeyModeHandlesAffects
W Translate Arrows with cone tips Position (X, Y, Z)
E Rotate Colored circles Rotation (degrees)
R Scale Lines with cube tips Scale (X, Y, Z)

Axis colors: X = Red, Y = Green, Z = Blue. Click and drag a handle to transform along that axis.

4. Weld

Welding combines all parts into a single mesh. Each part's transform is baked into its vertices, normals are re-transformed, and indices are merged. The result is one unified shape that can be exported or used as a building block.

5. Export

Three export modes for C++ code:

  • Geometry Only — just the PolarBuilder calls generating vertices, normals, colors, indices
  • With Dynamit Setup — builder code + Dynamit renderer configuration
  • Complete Standalone App — full GLFW application with camera, render loop, window setup

Projects can also be saved/loaded as .dproj JSON files.

Viewport

The 3D viewport uses a left-handed coordinate system: +X right, +Y up, +Z into screen. The camera orbits around the origin with spherical coordinates. Visualization helpers (axes, grid, light direction) can be toggled from the View Panel.

Technical Details

  • Built with C++17, OpenGL 3.3, GLFW, GLM
  • UI panels use Win32 ATL dialogs
  • Rendering via the Dynamit library with auto-generated GLSL shaders
  • Each shape gets its own Dynamit instance with vertex, normal, color, and index buffers
  • Transform order: Translate × RotateX × RotateY × RotateZ × Scale
  • Shape picking via Moller-Trumbore ray-triangle intersection
  • Project files are human-readable JSON (.dproj)
